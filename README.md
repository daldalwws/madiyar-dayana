# Свадебное приглашение — Мадияр & Даяна (26.09.2026)

Сайт-приглашение на свадьбу с анкетой для гостей. Без базы данных — ответы
сохраняются бесплатно в **Google Таблицу** через Google Apps Script.

**Что внутри:**
- 9 вариантов дизайна на выбор, тремя группами:
  - **по цвету** (одинаковая структура, разные палитры): `variant-classic.html`, `variant-minimal.html`, `variant-floral.html`, `variant-modern.html`;
  - **по структуре** (светлые, разная компоновка): `variant-stories.html` (сторис/полноэкран), `variant-timeline.html` (таймлайн), `variant-app.html` (вкладки как в приложении), `variant-envelope.html` (конверт → журнальная вёрстка);
  - **премиум-стиль · акварель** (как на референс-видео): `variant-watercolor.html` — обложка-конверт, акварельный Premier Hall, каллиграфия, тайминг, дресс-код, карта и **расширенная анкета** (присутствие/венчание/дети/кол-во детей). Нужны сгенерированные акварельные картинки — промпты в `img/wc/README.txt`;
- страница выбора `index.html` (показывает все 9);
- двуязычность **RU / KZ** (переключатель в правом верхнем углу);
- обратный отсчёт до свадьбы, фоновая музыка, места под фото;
- анкета: имя, фамилия, вариант присутствия (один / с парой / не смогу), пожелания;
- адаптив — всё рассчитано в первую очередь на телефоны.

## 1. Посмотреть варианты

Откройте `index.html` двойным кликом в браузере и выберите понравившийся дизайн.
> Заметка: фото и музыка появятся после шагов ниже; пока стоят заглушки.

## 2. Добавить свои фотографии

См. `img/README.txt`. Коротко: положите файлы `hero.jpg`, `gallery-1.jpg`…`gallery-4.jpg`
в папку `img/` и в выбранном html замените `…-placeholder.svg` на ваши имена файлов.

## 3. Добавить музыку

Положите аудио в папку `music/` под именем `track.mp3` (см. `music/README.txt`).
На сайте музыка включается круглой кнопкой ♪ внизу справа (автозапуск браузеры запрещают).

## 4. Анкета → Google Таблицы (бесплатно, без БД)

1. Создайте таблицу: открыть https://sheets.new
2. Меню **Расширения → Apps Script**.
3. Удалите код в редакторе и вставьте целиком содержимое файла **`google-apps-script.gs`**.
4. Сохраните (значок дискеты).
5. **Deploy → New deployment** → шестерёнка → тип **Web app**:
   - **Execute as:** Me (вы)
   - **Who has access:** Anyone (Все)
   - нажмите **Deploy**, разрешите доступ к аккаунту Google.
6. Скопируйте **Web app URL** (заканчивается на `/exec`).
7. Откройте **`assets/rsvp.js`** и вставьте URL в первую строку:
   ```js
   const SCRIPT_URL = "https://script.google.com/macros/s/XXXX/exec";
   ```
8. Готово — ответы гостей будут появляться в таблице на листе «Ответы».

> Проверка: откройте сам Web app URL в браузере — должна появиться надпись
> «OK — анкета… готова принимать ответы».
> Если меняете код скрипта позже — делайте **Deploy → Manage deployments → Edit → New version**.

## 5. Опубликовать на GitHub Pages

1. Создайте репозиторий на github.com и загрузите туда все файлы этой папки
   (можно перетащить через **Add file → Upload files**).
2. В репозитории: **Settings → Pages**.
3. **Source:** Deploy from a branch → **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`
5. Эту ссылку рассылайте гостям.

### Какой вариант показывать гостям
По адресу выше сначала открывается страница выбора (`index.html`).
Когда определитесь с дизайном — сделайте выбранный вариант главным:
- переименуйте, например, `variant-floral.html` → `index.html`
  (старый `index.html` сначала переименуйте, например, в `choose.html`),
- либо оставьте `index.html` как есть, а ссылку гостям дайте прямую,
  например `…github.io/repo/variant-floral.html`.
